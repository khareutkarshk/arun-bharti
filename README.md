# arunbharti.in — landing page demo

Single-page demo for Arun Bharti, MP Jamui (Bihar), Chief Whip, LJP(RV). English and Hindi.

Next.js 15 · Tailwind 4 · GSAP ScrollTrigger · Lenis · Anek Latin / Anek Devanagari.

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # static export in out/
```

Copy lives in `src/content.ts` (both languages). Bihar map data in `src/data/bihar.json`.

Photographs of Sansad Bhavan, Jhajha station and a Siwan paddy field are CC BY-SA 4.0 via Wikimedia Commons; credits in the footer and `assets/credits.json`.

Before launch, confirm: office email, social links, Rajgir venue, Purnia date, and the Jamui project-tracker claim.
